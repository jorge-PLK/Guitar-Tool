# WinApp

Interfaz de Windows (Fase 7c, paso 8, ADR-020): paquete SwiftPM solo x64 (en macOS compila vacío). El SDK de WebView2 sale de NuGet con SHA (`Tools/win/fetch-webview2.sh`) y `build.sh` lo copia a `C:\tf-webview2`.

| Fichero | qué hace (ADR-020) |
| --- | --- |
| `WinApp/Package.swift`, `Sources/CWebView2Host/` | Objetivos `CWebView2Host` (shim C++/COM: ventana Win32, WebView2 con loader estático, hosts virtuales `app.toneforge` para las páginas y `media.toneforge` para la carpeta de proyectos, mensajes y captura PNG) y `ToneForge` |
| `WinApp/Sources/ToneForge/main.swift` | Ejecutable `ToneForge.exe`: une el anfitrión con `Bridge`; diálogos nativos `IFileOpenDialog` desde un hilo propio; `writeStd` con `GetStdHandle` + `WriteFile` (el exe GUI no tiene handles estándar; con `FileHandle.standardError` abortaba al hacer doble clic) |
| `WinApp/Web/index.html`, `app.js`, `bridge.js`, `state.js`, `ui.js`, `html.js`, `icons.js`, `tokens.css`, `styles.css` | Carcasa: navegación, cliente del puente (límite de 15 s por llamada, `bridge.js:7`) y `tokens.css` sacado de los bocetos |
| `WinApp/Web/screens/` | `library.js`, `library-dialogs.js`, `import-files.js`, `link-sheet.js` (Biblioteca, diálogos, soltar ficheros y hoja de enlace); `backing.js`; `tab.js`, con sus `.css` |
| `WinApp/Web/backing/` | Backing: `mixer.js`, `strip.js`, `canvas.js`, `grid.js`, `chords.js`, `chord-editor.js`, `sections.js`, `section-drag.js`, `controls.js`, `diagram.js`, `model.js` (`snapRange` como `BeatGrid.snap`), `store.js` y simulados `mock-*.js`, `demo.js` |
| `WinApp/Sources/CWebView2Host/`, `WinApp/Sources/ToneForge/main.swift` (ola 2) | Anfitrión: `tfhost_init_ui_thread()` deja el hilo de UI en STA y se llama lo primero, antes de crear el `Bridge` (si Media Foundation lo pone en MTA, WebView2 no se crea: spec); `tfhost_create` falla con mensaje claro si el hilo ya es MTA. Navegador oculto (`tfhost_hidden_load`, `tfhost_hidden_cancel`: segundo WebView2 InPrivate para Songsterr, una carga a la vez con `AsyncMutex`) y vista previa visible (`tfhost_preview_show`, `tfhost_preview_hide`) |
| `WinApp/Web/record/`, `screens/record.js`, `screens/record.css` (ola 2) | Grabar y «Ver toma»: `bar.js`, `mixer.js`, `parts.js`, `preview.js`, `punch.js`, `store.js`, `viewer.js`, `take-screen.js`, `offset-sheet.js` (hoja «Ajustar desfase» con `takeview.openOffset`), `take-sync.js` (`CoreClock` y `VideoFollower`: el vídeo sigue el reloj del núcleo), `bits.js` |
| `WinApp/Web/montage/`, `screens/montage.js`, `screens/montage.css` (ola 2) | Montaje: `columns.js` (`FitText` con 4 % de holgura), `model.js`, `sheet.js`, `store.js`, `timeline.js`; `frames.js` recibe `frames.<canal>` y pinta el JPEG |
| `WinApp/Web/settings/`, `screens/settings.js`, `screens/settings.css` (ola 2) | Ajustes: `audio.js`, `audio.css`, `calibration-sheet.js`, `device-card.js`, `library.js`, `video.js` (vista previa con giro 90/270, candado en permiso denegado), `common.js` |
| `WinApp/Web/playlist/`, `screens/playlist-sheet.js`, `tab/songsterr-sheet.css`, `mock/` (ola 2) | Hoja de listas y de Songsterr; `mock/` gana `audio.js`, `montage.js`, `playlist.js`, `record.js`, `settings.js`, `songsterr.js`. Fuentes Inter y Space Grotesk (TTF, `Tools/fonts-to-ttf.py`) en las dos apps; `node --check` de todo `Web/` limpio |
| `WinApp/Web/tab/`, `vendor/`, `mock/`, `fonts/` | Tablatura (`frame.js`, `keys.js`, `store.js`, `mock-tab.js`; alphaTab y `tf-bridge.js` se copian al compilar); Preact, htm y signals vendorizados (`vendor/VERSIONS.md`); respuestas simuladas; `fonts/` sin usar (no borrar sin un sí de Jorge) |
