# FlutterApp

| Fichero | qué hace (ADR-021) |
| --- | --- |
| `FlutterApp/lib/core/` (`ffi_bindings`, `core_client`, `call_timeouts`, `host_services`, `frame_channel`, `mock_core`, `launch_options`, `core_providers`) | Puente con el núcleo: enlaces FFI, `CoreClient` (llamadas con tiempos de espera de `call_timeouts`), `HostServices` (peticiones `hostRequest`), `FrameChannel` (píxeles crudos), `MockCore`, `LaunchOptions` y los providers de Riverpod |
| `FlutterApp/lib/theme/` (`tokens`, `typography`, `fmt`, `icons`, `icons_data*`) | Tokens `TfColors`/`TfRadius`/`TfSize`, tipografía, formato (`Fmt`) e iconos `TfIcons` (trazos de Lucide en `icons_data*.dart`) |
| `FlutterApp/lib/widgets/` (`tf_*.dart`) | Kit de widgets compartidos, un fichero por componente, incluido `tf_video_surface.dart` (`TfVideoSurface`, textura de vídeo; recibe `frameSize` por parámetro) |
| `FlutterApp/lib/shell/` (`shell_route`, `shell_providers`, `shell_screen`, `snapshot`) | Carcasa con barra lateral y seis rutas, estado de la carcasa y `--snapshot` |
| `FlutterApp/lib/features/<área>/` | Pantallas provisionales por área (`backing`, `library`, `montage`, `record`, `settings`, `tab`); Ajustes con 3 pestañas |
| `FlutterApp/lib/features/backing/` (`backing_screen`, `backing_header`, `backing_chooser`, `backing_layout`, `backing_shortcuts`, `analysis_banner`, `not_separated_card`, `separated_projects`, `chord_vocabulary_provider`, `study_position`, `study_store`, `study_store_sections`) (Fase 7f, ola 2) | Pantalla Backing: `BackingScreen`, `BackingHeader`, `BackingChooser`, `FillLastLayout`, intents de teclado (`TogglePlayIntent`, `DeleteSectionIntent`), `BannerBox`/`LoadErrorBanner`, `NotSeparatedCard`, `separatedProjectsProvider`, `chordVocabularyProvider` (`study.chordVocabulary`), `studyPositionProvider` (`study.position`) y `StudyStore`/`StudyStoreState` (`StudyLoadStatus`; secciones en `StudyStoreSections`) |
| `FlutterApp/lib/features/backing/widgets/` (acordes: `chords_area`, `chords_header`, `chords_expanded`, `chord_strip`, `chord_strip_menu`, `chord_grid*`, `chord_chip`, `chord_editor*`, `chord_diagram*`, `chord_shape`) (ola 2) | Zona de acordes: tira y rejilla (`ChordStrip`, `ChordGrid`, `ChordGridGeometry`), editor (`ChordEditor`, `ChordEditorGrid`), diagrama (`ChordDiagram`, `ChordShape`, `ChordBarre`; formas de `study.chordShape`) y preferencia de expandido (`ChordsExpandedPrefStore`) |
| `FlutterApp/lib/features/backing/widgets/` (tiempo: `timeline_card`, `position_bar`, `transport_row`, `loop_pill`, `loop_marking`, `section_*`, `info_row`) (ola 2) | Línea de tiempo y secciones: `TimelineCard`, `PositionBar`, `TransportRow`, `LoopPill`, `pendingLoopStartProvider`; secciones con `StripSectionBoxes`/`GridSectionBoxes`, `SectionEdgeHandle` y `sectionEdgePreviewProvider` (`study.previewSectionEdge`), `SectionPopover`, `sectionSelectionProvider` |
| `FlutterApp/lib/features/backing/widgets/` (mezcla: `mixer_card`, `mixer_channel`, `mixer_levels`, `master_channel`, `compact_mixer`, `guitar_stereo_toggle`) (ola 2) | Mezclador: `MixerCard`, `MixerChannel`, `MasterChannel`, `CompactMixer`, `GuitarStereoToggle`, `mixerLevelsProvider` |
| `FlutterApp/lib/features/tab/` (`tab_screen`, `tab_stage`, `tab_card`, `tab_canvas`, `tab_canvas_controller`, `tab_store`, `tab_store_edit`, `tab_shortcuts`) (ola 2) | Pantalla Tablatura: `TabScreen`, `TabStage`, `TabCard`, `TabCanvas` (alphaTab en WebView; `TabCanvasState`), `TabStoreState` y edición con deshacer (`TabStoreEdit`), `TabShortcuts` |
| `FlutterApp/lib/features/tab/` (`tab_header`, `tab_footer`, `tab_transport`, `tab_track_*`, `tab_edit_bar`, `tab_listen_selector`, `tab_loop_menu`, `tab_source_menu`, `tab_theme_chooser`, `tab_notice`, `tab_pending_pill`, `tab_phase_overlay`, `tab_confirm_auto`) (ola 2) | Controles de la pantalla: cabecera y pie por código (`header`, `selection.summary`), transporte, pistas (`TabTrackStrip`, `TabTrackPill`, `TabTrackControls`), barra de edición, menús de bucle y fuente, tema, avisos (`TabNotice`, `tab.dismissNotices`) y fases de transcripción; `tabSavePathProvider`/`tabExportDataProvider` para exportar `.gp` |
| `FlutterApp/lib/features/tab/` (`songsterr_*`) (ola 2) | Hoja de Songsterr: `SongsterrSheetHost`, `songsterrStoreProvider`/`SongsterrStoreState`, `SongsterrChoosing`, `SongsterrPairing`/`SongsterrPairingRow`, `SongsterrWorking`, `SongsterrFailed`, `SongsterrIssueBox` y `SongsterrPreview` (vista oculta; user agent propio en Dart) |
| `FlutterApp/lib/l10n/` | ARB es/en con un bloque ancla por área (`<área>Anchor`); el código generado está versionado |
| `FlutterApp/test/support/harness.dart`, `shell_harness.dart` | Arneses de test para widgets y para la carcasa |
| `FlutterApp/test/theme/no_literals_test.dart` | Prohíbe literales de texto de cara al usuario en `lib/`; exención con `// tf-literal-ok: <motivo>` |
| `FlutterApp/test/**/goldens/` | Goldens; se regeneran con `TF_UPDATE_GOLDENS=1` |

Ejecución: `Tools/test.sh FlutterApp <ruta|nombre>` filtra los tests por ruta o por nombre.
